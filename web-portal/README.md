# Web Portal - Clínicas e Petshops

Painel web para veterinários e petshops consultarem e atualizarem o prontuário dos pets.

## Características desejadas

- Acesso controlado por perfil (veterinário / petshop)
- Visualização completa do histórico
- Registro de consultas, vacinas e serviços
- Integração com sistemas existentes (futuro)

## Stack sugerida

- React / Next.js
