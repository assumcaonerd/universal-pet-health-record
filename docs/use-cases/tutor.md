# Caso de Uso: Tutor

## Visão Geral

O tutor utiliza o aplicativo mobile para registrar, consultar e compartilhar o histórico de saúde do seu pet.

## Principais Funcionalidades

- Cadastro e edição do perfil do pet
- Registro de vacinas, consultas e tratamentos
- Acesso offline aos dados
- Compartilhamento seguro com veterinários e petshops
- Notificações de vacinas e retornos

## Fluxos Principais

1. Cadastro inicial do pet
2. Registro de vacinação
3. Consulta ao histórico médico
4. Compartilhamento de acesso com clínica
