# Caso de Uso: Petshop

## Visão Geral

O petshop utiliza o portal para consultar informações relevantes do pet (vacinas, alergias, restrições) e registrar serviços prestados.

## Principais Funcionalidades

- Consulta rápida de status de vacinas e alertas de saúde
- Registro de serviços (banho, tosa, hospedagem)
- Notas sobre comportamento ou condições observadas
- Integração com sistemas de agenda e caixa

## Fluxos Principais

1. Busca do pet por identificador ou tutor
2. Verificação de status sanitário
3. Registro de serviço realizado
4. Compartilhamento de observações com o tutor
