# Mobile App - Tutor (Offline First)

Aplicativo para o tutor gerenciar o prontuário de saúde do pet.

## Características desejadas

- Offline First
- Sincronização segura quando online
- Cadastro e edição de pets
- Registro de vacinas e eventos de saúde
- Compartilhamento de acesso com profissionais

## Stack sugerida

- Flutter ou React Native
